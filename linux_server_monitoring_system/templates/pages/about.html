About the Platform Academic & Production Ready

Centralized Agentless Linux Server Telemetry System

A full-stack, enterprise-grade web application engineered to monitor distributed Linux server nodes securely over SSH. The system provides automated real-time telemetry extraction (CPU load, memory allocation, disk partitions, network bandwidth), multi-tier Role-Based Access Control (RBAC), threshold rule evaluation, and centralized alerting.

Security First

Agentless SSH with RSA key authentication, strict RBAC permissions, and encrypted session management.

Automated Pipeline

Asynchronous metric sampling runner evaluating system health against configurable threshold policies.

Clean Architecture

Decoupled Django REST API, responsive Bootstrap 5 theme, and standard systemd / Nginx production configs.
